Antrenor: prototip

Apasă pe butoane, rânduri și pe bara de jos. Săgeata din stânga sus = înapoi.
Ecran:
  • Intră → Azi
  • Rând grupă → Prezența (apasă data pentru altă zi, apoi 13 pentru avertizare)
  • Rând lecție → Prezența lecției
  • + Lecție individuală → Durată
  • Grupe → grupa ta / grupa altui antrenor → Înlocuiesc azi
  • Grupa mea → + Adaugă sportiv → caută / sportiv nou
  • Profil → Setări cont
