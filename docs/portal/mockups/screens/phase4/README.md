## Notes

- Copy rules: no middle dot, no em dash, straight quotes in all new copy. The website captures keep two existing texts that contain a middle dot (the CMS notebook subtitle and the TEST calendar tile "Weekend curs"); changing them is a separate copy decision.
- TEST database (read-only, default_transaction_read_only): `programs` and `team_members` are empty; `calendar_events` has one Școala event "Weekend curs"; `club_groups` holds the canonical groups plus "Performanță" (Club) and "Grupa Mică" / "Grupa Mare" (second test school). Legacy names therefore come from data/seed/content.json, backups/program-page-pre-legacy-cleanup-2026-09-17.json, scripts/seed-content.js, scripts/seed-calendar-sample.js and the live-site read of 19 oct (data-q1-groups). Nothing was written to any database.
- Club schedule times (Profesioniști, Avansați) are examples.

## New season (sezon-nou-a, sezon-nou-b)

Built 2026-10-27 after the phase 4 spec review (new-season flow designed inside phase 4). Same real admin CSS and components, plus the Sezoane page (SezoanePage.tsx: Sezon, Perioadă, Taxă de membru, Curent) and StatTile, Checkbox, Notice. Generated by `gen_sezon_nou.py`, run from `gen_phase4.py`. Example: 2026-2027 has 89 children (7 Școala groups, 2 Club groups, 3 children in both sections, 2 inactive); Club copied, Școala left empty: 14 copied, 73 go to "Fără grupă". Children synthetic.

| File | Shows |
|---|---|
| sezon-nou-a.html | Start on Sezoane: "Începe sezonul 2027-2028" on the season after the current one; one window, 3 steps (what changes when it becomes current, groups, preview); applied in one go; toast with "Anulează" (and the no-undo variant); Sezoane after; "Fără grupă" with last season's group proposed; "Copiază sportivii / programul din 2026-2027" on an empty group tab. |
| sezon-nou-b.html | Start on Grupe: banner "Sezonul 2027-2028 nu are încă grupe." with "Pregătește sezonul"; window of 2 steps (groups, preview), the website does not change; "Fă sezonul curent" separately on Sezoane with a confirmation that lists what changes and warns when the groups have no program yet. |

Open questions (recommended option first):

1. Start and making the season current: A (Sezoane "Începe sezonul", one window makes it current and prepares the groups) or B (Grupe banner, "Fă sezonul curent" separate)? Recommended A: the website program is never empty and nothing is left half done.
2. Defaults per group: "Copiază sportivii" off for Școala and on for Club, "Copiază programul" on for all (repeats from the season start to its end), ticks per section header: ok? Recommended yes.
3. "Vezi sportivii" lists the children with their main group in the new season and lets you untick leavers before copying; inactive children are never copied: keep? Recommended keep.
4. Children not copied become "Fără grupă" in the new season with last season's main group proposed and the source line "Din 2026-2027"; A.C.S. starts at Nu: ok? Recommended yes.
5. Safety: preview of counts plus a toast with "Anulează" for 8 s (as every phase 4 action), or preview with a warning and no undo? Recommended the toast.
6. Later, per group: an empty Sportivi or Program tab offers "Copiază sportivii / programul din 2026-2027"; breaks (Pauze) are not copied: ok? Recommended yes.
