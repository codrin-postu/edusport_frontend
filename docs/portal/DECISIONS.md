## Proposed (CMS admin: registrations -> documents -> members -> Școala groups -> check-in, screen mockups/screens/admin-cms-v1.html, generator mockups/gen_admin_cms.py)
- Facts: the website form posts to Strapi (`POST /api/forms/inscriere`); Strapi already mirrors registrations one-way to Google Sheets via the Sheets API (service account, instant + hourly reconcile). No PDF code exists yet.
- The old Apps Script form (`script.google.com/.../exec`) submits through `google.script.run.processForm` (not a public endpoint) and returns `acordUrl`: an "Acord Părinți" document the parent downloads and signs by hand at the first class. Its form has extra fields: calitate față de sportiv (+ altă calitate), înălțime, sezonul trecut, membruACS Da/Nu, abonament ales (prices from a settings sheet, options depend on membership), sursă (list + Altele).
- Proposal: generate the PDF ("Acord părinți", fields auto-filled) in our backend on every registration; store it privately (opens only from the CMS after login); link it in the CMS (Înscrieri panel + new Documente page) and in the synced Sheet (new "Document" column linking into the CMS). File names `Nume_Prenume_Tip-document_Sezon.pdf` (no diacritics). Documente page: search, filter by season and type, sort, single download, multi-select ZIP and "whole season" ZIP; regenerate after corrections.
- "Confirmă și adaugă în club" on a registration creates the private club member (prefilled), sets the parent's portal access, membership for the season and the Școala group(s).
- New CMS pages: Școala de patinaj (season totals: athletes, members, groups, confirmed without group; per-group count/occupancy/members) and admin Prezență per day with one column per hour, so an athlete can be ticked at another hour than their group (+1 oră marker).
