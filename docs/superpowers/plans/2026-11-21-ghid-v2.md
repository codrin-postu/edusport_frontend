# Ghid v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Restructure the staff wiki into 9 collapsible groups, one flow per page, fix content errors, make screenshot marks match their step, add missing pages, and document new-host install in the repos.

**Architecture:** Same platform (src/lib/ghid, src/components/ghid, src/content/ghid). Registry becomes group -> pages. Marks get string keys in the shot config; each step names the keys it means and the number shown is the key's position in that step.

**Tech Stack:** Next.js 15, TypeScript, Tailwind tokens, Playwright (shots script and e2e), node --test.

**Inputs (read, binding):**
- `.superpowers/ghid-v2/content-review.md` (tree, per-page fixes, gaps)
- `.superpowers/ghid-v2/shots-audit.md` (per-shot verdicts and fixes)
- `.superpowers/ghid-v2/install-facts.md` (Task 8 only)
- Original spec `docs/superpowers/specs/2026-11-19-ghid-design.md`; content rules `.superpowers/sdd/2026-11-19-ghid/content-common.md`.

## Decisions (user, 2026-11-21: "ok build" on these proposals)

- 9 groups, in this order: Început; Înscrieri; Sportivi; Grupe și program; Prezență; Bani (includes Tabele pages as the last pages, "Rapoarte" is not a separate group); Site și anunțuri; Echipa și acces (includes the Date personale pages, last); Despre EduSport (Siguranță, Găzduire).
- Page list per group = content-review section 1 tree, with the two folds above.
- Sidebar: each group is a collapsible (native details/summary), open when it holds the current page, others closed; square chevron, no rounded shapes; page count on closed groups; same list in the phone Cuprins.
- Marks: numbered 1..n per step from the step's own `marks` list; badge inside the box, top-left.
- Install steps go to the backend repo docs, not the wiki.
- New pages now: Contul tău (parolă și 2FA), Început de sezon, Alte formulare, Profil public și rezultate, Adaugă sau prelungește un abonament, Lecții individuale (walk the screens first; drop if the screens do not exist), Echipa sponsori și alte liste, Setări site, Unește/inactiv/șterge steps. Deferred (not written): Membru A.C.S. (waits for the manual tick), Acces părinte, Schimbă formularul de înscriere.

## Global Constraints

- Romanian UI copy, terse; no em or en dash, no middle dot, straight quotes, no emoji, only `**bold**` inline; real on-screen labels in bold; never invent facts (unchecked claims are left out; club-only facts go to the report as COPY NEEDED).
- No rounded pills or circles, no dashed or dotted lines; portal tokens only (npm run check:tokens).
- Behaviour tests only; no visual/screenshot assertions.
- Screenshots only from the local test environment (invented data). Competition names on site shots are replaced or not shown.
- Checks per task: npm run lint, npx tsc --noEmit (delete .next-e2e first), npm run check:tokens, npm run test:scripts, npx playwright test -c playwright.e2e.config.ts tests/e2e/ghid.spec.ts --workers=2; delete .next-e2e after. Never stop or disturb the dev server on port 3011.
- Commits: Conventional Commits, no AI attribution, no Co-Authored-By. Never push.

## Review Focus

- A step with a shot but no `marks` shows the image with no marks (not all marks).
- A mark key named in a step but missing from shots.json fails the content test, not silently.
- Renamed or split pages: every `links` block and prev/next still resolve (registry test).
- Lead text with `**` renders bold, never literal asterisks.
- Collapsible state: the current page's group is open on direct load and after client navigation.
