# Ghid EduSport Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A password-protected staff wiki at `/ghid` on the public site, with the admin part's pages, real screenshots and search.

**Architecture:** A new root route group `src/app/(ghid)` with its own layout in the portal theme. The middleware gates every `/ghid/**` path on a signed cookie; a server action sets it. Pages are typed TypeScript data rendered by a small set of block components; screenshots are JPGs plus a marks JSON produced by a Playwright script and served by a gated route handler.

**Tech Stack:** Next.js 15 (App Router, standalone), TypeScript, Tailwind v4 with the portal tokens, Playwright (e2e and the shots script), `node --test` for pure modules (Node type stripping, no new dependencies).

**Spec:** `docs/superpowers/specs/2026-11-19-ghid-design.md`. Approved mockup: https://claude.ai/artifact/WnjWE7WpSSrYKisKp422w9 (source: `/private/tmp/claude-501/-Users-codrin-Documents-Programming/7f5c4386-1f07-4c19-944f-a16f49a53ebd/scratchpad/ghid/ghid.tpl.html`).

## Global Constraints

- Password env `GHID_PASSWORD`; never in git. Missing or empty: every password is refused (fail closed).
- Cookie `ghid`: value `HMAC-SHA256(password, "ghid-v1")` base64url; httpOnly, Secure in production, SameSite=Lax, path `/ghid`, max age 180 days.
- Rate limit: 10 failed attempts per IP per 15 minutes, key from `X-Real-IP`; in memory.
- Every `/ghid` response carries `X-Robots-Tag: noindex, nofollow`; robots has `Disallow: /ghid`; not in the sitemap.
- Public site host only; portal hosts already 404 anything outside their app.
- Look: portal theme (`data-theme="portal"`), Inter text, League Spartan 800 headings, square corners. Layout as the mockup: navy top bar with search, contents rail left (desktop), "Cuprins" button + search field (phone), article column max 860 px for shots.
- Frontend token rules (`npm run check:tokens`): theme tokens only, no opacity utilities except 0/100, 4 px grid, no arbitrary px, no radius, z-index tokens, `<Icon name>` not lucide. The mockup's translucent search field becomes a token colour.
- Copy (Romanian, exact): "Ghid EduSport", "Parolă", "Intră", "Parolă greșită.", "Prea multe încercări. Încearcă din nou peste 15 minute.", "Caută în ghid", "Cuprins", "Înapoi", "Înainte", "Atenție", "Video", "Niciun rezultat.". No em or en dash, no middle dot, straight quotes, terse.
- Screenshots only from the local test environment (invented names). JPG 1280 px wide, quality 80.
- Any fact on Siguranță, Plăți safety and Găzduire is checked (backend code path, `ssh edusport-vm`, or a dated public price page) and the check is listed in the task report. Unchecked claims are left out.
- Content text may be drafted with the Fable model, then trimmed by the implementer to these rules.
- Commits: Conventional Commits, no AI attribution, never push.

## Review Focus

- `next` pointing outside the wiki (`//evil.com`, `https://x`, `/ghid/../admin`): after the password the user lands on `/ghid`, never off-site. Test in Task 2.
- Missing `GHID_PASSWORD` on a fresh server: the right-looking password is refused, nothing opens. Test in Task 1 (`ghid-gate.test.mjs`).
- Image path tricks (`/ghid/img/../../package.json`, encoded `%2e%2e`): 404, never a file outside `content/ghid/img`. Test in Task 3.
- A search of only spaces, or a word typed without diacritics ("plata"): no result list for blanks, matches for the plain spelling. Test in Task 4 (`ghid-search.test.mjs`) and e2e.
- An unknown page slug (`/ghid/nu-exista`) with a valid cookie: the 404 page, not a crash. Test in Task 3.
